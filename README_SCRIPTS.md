# دليل استخدام ملفات إضافة العارضين والمنتجات
# Guide for Using Exhibitors and Products Addition Scripts

## الملفات المتاحة - Available Files

### 1. add_exhibitors_with_products.py
**الغرض**: إضافة عارضين جدد مع منتجاتهم
**Purpose**: Add new exhibitors with their products

**الميزات**:
- إنشاء حسابات مستخدمين جديدة للعارضين
- إنشاء ملفات شخصية للعارضين مع معلومات كاملة
- إنشاء الفئات إذا لم تكن موجودة
- إضافة 5-10 منتجات لكل عارض
- تجنب إضافة عارضين مكررين

**العارضين المتضمنين**:
1. Al-Noor Dairy Products (السعودية - منتجات الألبان)
2. Emirates Premium Spices (الإمارات - التوابل والأعشاب)
3. Nile Valley Fresh Fruits (مصر - الفواكه الطازجة)
4. Levant Traditional Bakery (الأردن - المخبوزات والمعجنات)
5. Gulf Premium Seafood (الكويت - المأكولات البحرية)
6. Moroccan Gold Olives (المغرب - الزيوت والتوابل)

### 2. add_sample_products.py (محسن)
**الغرض**: إضافة منتجات للعارضين الموجودين
**Purpose**: Add products to existing exhibitors

**الميزات المحسنة**:
- فحص العارضين الموجودين لتجنب التكرار
- إضافة 5-15 منتج لكل عارض (قابل للتخصيص)
- منتجات أكثر تنوعاً لكل فئة
- إحصائيات مفصلة عن العملية
- معالجة أفضل للأخطاء

## كيفية الاستخدام - How to Use

### إضافة عارضين جدد مع منتجاتهم:
```bash
python add_exhibitors_with_products.py
```

### إضافة منتجات للعارضين الموجودين:
```bash
python add_sample_products.py
```

## إعدادات قابلة للتخصيص - Customizable Settings

### في add_sample_products.py:
```python
PRODUCTS_PER_EXHIBITOR_MIN = 5  # الحد الأدنى للمنتجات
PRODUCTS_PER_EXHIBITOR_MAX = 15  # الحد الأقصى للمنتجات
```

1. **النسخ الاحتياطي**: تأكد من عمل نسخة احتياطية لقاعدة البيانات قبل التشغيل
2. **البيئة**: تأكد من تشغيل السكريبت في بيئة التطوير أولاً
3. **الصلاحيات**: تأكد من وجود صلاحيات الكتابة في قاعدة البيانات
4. **التحقق**: راجع النتائج بعد التشغيل للتأكد من صحة البيانات

## استكشاف الأخطاء - Troubleshooting

### خطأ في الاتصال بقاعدة البيانات:
- تأكد من تشغيل خادم قاعدة البيانات
- تحقق من إعدادات الاتصال في app.py

### خطأ في الفئات:
- تأكد من وجود جدول categories في قاعدة البيانات
- السكريبت سينشئ الفئات تلقائياً إذا لم تكن موجودة

### تكرار البيانات:
- السكريبت يتحقق من التكرار تلقائياً
- يمكن تشغيله عدة مرات بأمان
